Condiciones del servicio

1. Finalidad

Video Factory es una aplicación de escritorio de uso privado para preparar, organizar y publicar contenido audiovisual propio del canal Archivo del Viajero.

2. Usuario autorizado

La aplicación está destinada al propietario y a las personas expresamente autorizadas para administrar las cuentas del canal. No se ofrece como servicio público ni permite que terceros creen cuentas.

3. Contenido

El usuario autorizado es responsable de revisar el contenido antes de publicarlo y de respetar los derechos de autor, las normas de las plataformas y la legislación aplicable.

4. Integraciones

Las funciones de YouTube y TikTok dependen de sus APIs oficiales, permisos, límites y políticas. Las plataformas pueden modificar o suspender esas funciones.

5. Disponibilidad

La aplicación se proporciona para la gestión interna del canal, sin garantía de funcionamiento ininterrumpido. Las publicaciones requieren una confirmación explícita del usuario autorizado.

6. Contacto

Para consultas relacionadas con esta aplicación, utiliza los perfiles oficiales de Archivo del Viajero en YouTube o TikTok.
